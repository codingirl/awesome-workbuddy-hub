## 详情

> 之前做公文格式 Skill，我关心的是怎样把版式要求变成可重复执行的步骤。这次往国企专业场景里再走一步，我做了一个采购文件审查专家，已经在 WorkBuddy 公开发布。 它的名字是“国企采购文件审查专家”。经办写初稿、中层审核条款、管理层看风险与决策事项，都可以调用它。第一版重点落在信息化建设、咨询设计和运维服务采购。 这次开发里，我更在意的一件事是：专业人员积累的判断，怎样才能在离开原来的项目上下文之后，仍然被别人用起来。 格式可以固化，专业判断还需要保留前提 一条版式要求，可以明确写成字号、行距和位置。采购审查里的很多要求，却要先知道采购主体、资金性质、标的、地区，以及这家企业有效的制度和授权。 把过去某个项目的审批额度、付款比例或供应商数量复制到新项目，并不能让经验变得专业。一个地方国企也不能只凭“国企”两个字，就直接套用另一家企业的采购程序。 所以，这次整理规则时，我保留的是判断方法：先确认适用条件，再定位原文事实，区分法律要求、企业制度与管理建议，最后给出能够执行的改法。公司的真实项目、内部制度原文和供应商报价，没有放进公开专家包。 文件中的每条问题，还要分清处置方式。需要改正文的，说明改在哪里；能通过流程控制…

## 使用/获取

- 一般做法：按原项目 README / `SKILL.md` 的说明，把 Skill 导入 WorkBuddy（或放入技能目录）。
- ⚠️ 安装第三方 Skill 前请审阅其来源、许可证、会访问的文件/账号/网络权限。
