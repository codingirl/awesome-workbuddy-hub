# SkillLens

> 类型：技能（Skills） ｜ 分类：数据分析 ｜ 标签：Ready-to-use Skills、数据分析

## 简介

MIT 许可的自托管 Skill 评测工具，提供规则评分、证据、Deep Review 和改进建议，并支持 WorkBuddy Agent CLI；上传 Skill 到 Web UI 或调用模型评测前请确认数据范围

本条目收录自社区资源索引，简介见上；具体功能、适用场景与限制请以原项目页面为准。

## 使用/获取

- 链接：<https://github.com/AndrewNgGirl/SkillLens>
- 一般做法：按原项目 README / `SKILL.md` 的说明，把 Skill 导入 WorkBuddy（或放入技能目录）。
- ⚠️ 安装第三方 Skill 前请审阅其来源、许可证、会访问的文件/账号/网络权限。
