## 详情

> 准备在 WorkBuddy 卖 Skill 的朋友，注意一个坑。 如果你打算先免费上架，积累用户，等有了安装量再转成收费，目前还行不通。 查了下官方规则，有两个限制： ① 已发布的免费 Skill，暂时不能直接转为付费。官方说是为了不影响已安装用户的使用。 ② 想重新上传一个收费版？也没那么简单。

## 使用/获取

- 一般做法：按原项目 README / `SKILL.md` 的说明，把 Skill 导入 WorkBuddy（或放入技能目录）。
- ⚠️ 安装第三方 Skill 前请审阅其来源、许可证、会访问的文件/账号/网络权限。
