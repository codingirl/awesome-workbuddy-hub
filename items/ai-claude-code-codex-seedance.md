> 现在用 AI 生成一段视频，已经不算特别难了。 输入几句话，上传一张图片，点击生成，过一会儿就能看到画面动起来。 但如果你想制作一条真正完整、有故事、有镜头语言、人物和画风一致的短片，事情就没那么简单了。 人物走着走着换了一张脸。 上一秒还拿在手里的杯子，下一秒突然消失。 明明要求镜头向左移动，结果人物却往右跑。 最头疼的是，每次发现问题，往往还得重新生成。 AI 视频最贵的不是某一次生成，而是反复试错。 所以，这期不准备分享一堆看起来很厉害的视频提示词，而是介绍一套更值得借鉴的方法：让不同的 AI 工具各自负责擅长的事情，并在真正花钱生成视频之前，把大部分问题提前解决。 01｜不要让一个 AI 包办所有事情 如果你准备制作一部 AI 短片，大致会遇到三类不同工作。 第一类是创作决策：故事怎么写、镜头怎么安排、画风怎么确定？ 第二类是视觉设计：人物长什么样、场景如何构图、每个镜头的第一帧和最后一帧是什么？ 第三类才是视频生成：如何把已经确定的画面变成动态视频？ 与其让同一个模型从头做到尾，不如按照任务分工。 这里可以借鉴一套多模型组合： Claude Code / Codex + 图像生成工具 + Seedance + F…
