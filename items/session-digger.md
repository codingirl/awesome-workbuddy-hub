# Session Digger

> 类型：技能（Skills） ｜ 分类：数据分析 ｜ 标签：Skill collections、数据分析

## 简介

ISC 许可的跨 Agent 会话检索与知识管理工具，原生解析 `~/.workbuddy/projects`，用 SQLite FTS 建立增量索引并生成自包含本地报告

## 详情

本条目收录自社区资源索引，简介见上；具体功能、适用场景与限制请以原项目页面为准。

## 使用/获取

- 链接：<https://github.com/taxueseek/session-digger>
- 一般做法：按原项目 README / `SKILL.md` 的说明，把 Skill 导入 WorkBuddy（或放入技能目录）。
- ⚠️ 安装第三方 Skill 前请审阅其来源、许可证、会访问的文件/账号/网络权限。
