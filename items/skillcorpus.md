# SkillCorpus

> 类型：技能（Skills） ｜ 分类：效率 ｜ 标签：Skill collections、效率

## 简介

Apache-2.0 的 Skill 聚合与检索基础设施，提供 WorkBuddy 插件，可从多个来源查找并加载任务相关 Skill

## 详情

本条目收录自社区资源索引，简介见上；具体功能、适用场景与限制请以原项目页面为准。

## 使用/获取

- 链接：<https://github.com/EverMind-AI/SkillCorpus>
- 一般做法：按原项目 README / `SKILL.md` 的说明，把 Skill 导入 WorkBuddy（或放入技能目录）。
- ⚠️ 安装第三方 Skill 前请审阅其来源、许可证、会访问的文件/账号/网络权限。
