> 从 0 制作、上架、定价到第一笔订单，尾部附可以直接复制的 Skill 开发 全流程Prompt。 最近，我看到一个挺有意思的消息。 腾讯 WorkBuddy 开始支持开发者销售 AI Skill 了。 个人和企业都可以申请入驻，把自己开发的技能上架到平台，选择一次性收费或者按月订阅。 这让我想到一个问题： 未来，我们是不是可以像卖软件、卖电子书一样，把自己擅长的一项工作方法直接卖给别人？ 比如： 你很擅长 Excel 数据分析，可以把自己的分析流程做成一个 Skill。 你是小红书博主，可以把选题、标题、文案和封面制作整理成一个 Skill。 你负责公司销售运营，可以把每周重复做的销售报表，变成一个自动分析工具。 以前，这些能力往往只能靠自己花时间提供服务。 现在，它们有机会被封装成可重复使用的数字产品。 10 月 24 日，X 博主超级峰（@Mileson07）分享了一篇《WorkBuddy Skill 变现终极教程》。 我结合这篇文章和 WorkBuddy 官方文档，把它整理成了一份更适合普通人实践的指南。 但先说明一件事： 平台允许你卖 Skill，不代表一定有人愿意买。 真正重要的不是你做出了多少个 Skill，…

## 使用/获取

- 一般做法：按原项目 README / `SKILL.md` 的说明，把 Skill 导入 WorkBuddy（或放入技能目录）。
- ⚠️ 安装第三方 Skill 前请审阅其来源、许可证、会访问的文件/账号/网络权限。
