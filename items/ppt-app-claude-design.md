> 前段时间，Anthropic 推出了 Claude Design，可以用自然语言生成质量不错的网页和原型设计。效果确实比 Vibe Coding 那种清一色渐变蓝要好，但有个硬限制：你得是 Claude 订阅用户，而且跑两个任务，token 配额就基本见底了。 而我一直关注的 AI 开发者，花叔 @AlchainHust ，直接把 Claude Design 的工作机制逆向，重新封装成了一个开源 Skill，叫 Huashu Design。目前这个项目在 GitHub 上有 19,100 个 star、2,400 个 fork​，MIT 协议开源。 Claude Design 的底层逻辑是：理解需求 → 生成品牌规范 → 出产物 → 截图验证 → 修复。Huashu Design 把这套流程从 Claude 的产品界面里抽出来，变成任何 coding agent 都能调用的 Skill。项目内置了 40个 HTML 原生设计模板，20 个网页风格、20 个 PPT 风格。 安装之后，Claude Code、Cursor、Codex、国内的 Trae、QClaw、Workbuddy 都可以直接用。 这个skill我已经深度使…
