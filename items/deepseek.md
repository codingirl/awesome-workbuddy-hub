> 最近被问到一个卡点：在 WorkBuddy 或 codex 里配好了 DeepSeek 文本任务跑得挺顺，轮到出图、出视频，整条链路就断了 于是开始怀疑是不是配置写错了 其实配置没问题 是这个模型本来就不干这活 我的处理办法很直接 不要指望一个模型全包，把生图和生视频当成两个独立能力接进来 跑通一次，再封成 Skill，以后一句话就能调 先分清楚哪一层出的问题 DeepSeek 目前对外提供的是文本类模型 所以这不是"能力弱"的问题，是压根不在同一条产品线上 Agent 工作台的分工可以这么看： 文本模型负责"写清楚" 生图生视频模型负责"做出来" 工作台负责把两段接上 接生图 API 首先打开 API 聚合网站： 一个 API key，GPT Image、Seedance 这些图像/视频模型全部搞定，不用来回切换 API key，同时也可以在线 Playground 能直接试 现在注册会赠送2000积分，足够你前期测试了 注册后，首先创建一个 API key 模型广场选择一个生图模型，比如 gpt-image 网站提供了详细的文档说明，以及下 API 调用示例，而这些正是我们所需要的 你可以在线调试，也可以大概看看说明文…
