## 详情

> 先看效果。 上面这两张是装好之后跑出来的，一张是让它读图，一张是让它出图。 DeepSeek-V4-Flash 刚更新，性价比高，速度也快，唯一可惜的是它看不见图，也画不出图。你把一张截图丢过去，它只能告诉你它读不了。 正好有个模型把识图和生图都免费开放，我就想，能不能做成一个工具，让大家都用上识图和生图能力。 于是我做了个 MCP 不管你用 WorkBuddy 还是别的 Agent 客户端都能装，接下来以 WorkBuddy 为例。 装完之后，你就可以直接把图片丢给 DeepSeek 让它读，也可以让它按你的描述出图。整个过程还在原来那个对话框里，不用切别的工具。 首先介绍一下能力来源：Agnes AI 是一家专注全模态基础模型研发的，自主构建了覆盖文本、图像、视频等能力的模型，它们的策略是用免费换取使用数据。 所以其实还可以使用它们的文本模型和视频模型，但不在本mcp包含内容中，大家可以进阶尝试。 据官网介绍也可以接入OpenClaw、Hermes使用，欢迎大家分享使用感受。 踩坑提醒：大陆端点不支持拿到视频交付文件，所以MCP没有把这个内容做进去。欢迎大家按需自定制。 三分钟装好 第一步，注册账号拿 API Key …
