> 我现在用 WorkBuddy，最烦的不是 Skill 不够。而是事情刚跑到一半，模型这边先卡住：常用模型不顺手，想换一个试试，又得重新找接口。 尤其是 HY3 这种限时免费模型，福利在的时候当然舒服；但它一旦结束、额度收紧，工作流很容易突然断档。 以前我一看到 NVIDIA 大模型，第一反应就是显卡、Docker、显存。 后来才发现，普通人根本不用走本地部署那条路。 NVIDIA 有个 API Catalog。拿一个 API Key，填进 WorkBuddy 的自定义模型，就能多接一个模型入口。 不是让你买显卡，也不是教你把 Mac 搞成机房。 所以这篇不是叫你抛弃 HY3。 而是趁还能用的时候，先把 NVIDIA 这条备用线路接好。 主力继续用你最顺手的，备用模型在关键时候顶上。这样才不至于哪天模型列表一变，自己的工作节奏也跟着停。 先说结论：NVIDIA 和 WorkBuddy，各自强在哪、弱在哪？ NVIDIA API 的优点 不用本地显卡。调的是 NVIDIA 托管接口，Mac 也能直接用。 接入成本低。接口兼容常见的 Chat Completions 格式，WorkBuddy 正好能填自定义模型。 不是单一模型。…
