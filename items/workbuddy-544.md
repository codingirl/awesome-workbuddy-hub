## 详情

> 说真的，在 WorkBuddy 里生图，别直接选生图模型。 群里有人摸出个更好用的办法：选语言模型，把 API 地址和 key 交给它，告诉它「以后生图都这么调」。提示词它自己写，会补上很多你想不到的细节，出来的图反而更好。 直接选生图模型能出图，但存不下来，最后还得切回语言模型让它保存到本地。
