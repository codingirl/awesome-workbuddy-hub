# yao-meta-skill：元 Skill（创建/评测/打包）

> 类型：技能（Skills） ｜ 分类：开发 ｜ 标签：开发

## 简介

把工作流、提示词、SOP 做成可复用 Skill，支持创建、评测、打包；适配 WorkBuddy 官方文档

## 详情

以下内容整理自原帖/文章（节选，未做编造；完整内容请见来源链接）：

> 最近不少朋友在用WorkBuddy 结合官方文档，给元Skill做了一版规范适配升级 开源给大家 一键安装部署后 把工作流、提示词、SOP做成可复用的Skill，支持创建、评测和打包 安装部署方式，在WorkBuddy中发送： “帮我把 WorkBuddy 项目，并完成配置和自检。”

## 使用/获取

- 一般做法：按原项目 README / `SKILL.md` 的说明，把 Skill 导入 WorkBuddy（或放入技能目录）。
- ⚠️ 安装第三方 Skill 前请审阅其来源、许可证、会访问的文件/账号/网络权限。
