> 我以前对国内 Agent 有一个很明显的偏见。 Claude Code 和 Codex 出来的时候，我一直在用。它们能读文件、改代码、跑命令，也能围绕一个任务持续往下做。用顺手以后，我很自然地觉得，国外这些 Agent 已经把体验做得够好了，国内产品大概很难真正跟上。 后来我发现自己把问题想窄了。在很多人都在讲WorkBuddy的时候好我就在想 判断一个 Agent 好不好用，模型能力当然重要。你把一个复杂任务交给它，它能不能理解，能不能少犯错，能不能把事情推进下去，这些都直接影响结果。 但真正用起来以后，还有一件事会反复影响体验，那就是生态。 模型能不能直接用，工具和技能是否已经配好，中文工作场景是否顺手，注册和网络配置有没有额外门槛，文件和权限能不能让人看得明白，这些细节加在一起，决定了一个 Agent 能不能进入日常工作。 这也是我后来开始用 WorkBuddy 的原因。 我不把它说成在所有方面都已经超过 Codex 或 Claude Code。不同工具擅长的任务不同，开发者和普通办公用户的要求也不一样。我的感受是，WorkBuddy 在国内使用环境里把很多事情提前准备好了，特别适合想从 AI 工具开始上手，又不想先…
