## 简介

MIT 许可的本地优先 Token 用量与成本看板，明确支持 WorkBuddy，通过 SessionEnd Hook 和本地项目日志统计用量，提供桌面应用、CLI、限额和趋势视图；默认不需要云账号或 API Key，…
