## 详情

> 最近我用 WorkBuddy 跑通了一条财经视频生成流程。 先说清楚：我使用的“视频生成专家”Skill，只负责基于 Remotion 生成无声视频和视频项目文件，不生成音频。 配音是我后续自己调用火山引擎(豆包语音) TTS API 生成的；字幕时间轴则用 Whisper 对齐。最后再回到 Remotion 网页预览音画效果，确认没问题后渲染合成最终 MP4。 这个只是我测试workbuddy到底行不行，后面还要整合几个skill. 内容可能写得有点不详细，后面再继续更新。 写这个主要目的是workbuddy和codex比较一下。 codex一到下午就很容易失联。 如果还没注册，可以通过我的邀请链接进入： 第一步：进入专家技能页面 打开 WorkBuddy 后，在左侧找到“专家·技能·连接器”。 进入后，右侧会有不同场景分类。选择“内容创作”，这里集合了视频脚本、短视频运营、剪辑、PPT 等多种 Skill。 第二步：选择视频生成专家 在“内容创作”分类里找到“视频生成专家”。 这个 Skill 基于 Remotion，适合生成带数据图表、文字动画、转场和节奏设计的视频。它更像一个可编程的视频工作台，不是简单把几张图片拼…
