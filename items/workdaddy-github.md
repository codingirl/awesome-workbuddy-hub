> WorkDaddy 是 GitHub 上的一款开源第三方工具 为腾讯的 WorkBuddy 和 CodeBuddy 桌面客户端提供多账号管理、界面主题、提示词管理和自动化任务等增强功能。它通过本机的调试接口向客户端注入功能，不修改官方安装包，账号和配置数据全部保存在本地电脑上。 🔗
