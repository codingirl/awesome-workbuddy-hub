## 详情

> 我们知道现在技能库也就是 Skills 满天飞。虽然 Workbuddy 内置了很多智能体技能，但是我们很多需求都需要自己改改重新包装下，这个时候网上优化过的技能库就有用多了。当你看到别人分析的技能库非常不错，基本上源码都放在 github 上托管，安装起来一般看 README 都是需要自己下载安装，很麻烦。今天分享的就是利用 workbuddy 桌面版本来快速构建自己的技能库流水线。 通过 workbuddy，我验证了通过大模型让它帮我直接安装使用各种代码库，很多库并不是技能，所以你需要要求大模型帮我创建技能，这个时候就能看到 Workbuddy 的好处了，我把验证的方法推荐给大家使用。 今天遇到这个库daily_stock_analysis，没有专用的技能库，需要托管到 github action 使用，我就想了一个办法，先把它下载下来，让 workbuddy 参考改造成 Skill 并安装到我的技能库中，利用自动化板块帮我每天自动化跑任务，我就每天看报告就可以了。 我安装完技能库之后，直接安排一个任务让它每天都跑一遍。这样每天就有了通过调研分析之后可以推荐的股票代码了。对于个人美股分析投资总是有点帮助的。 这是最后运…
