> 很多人第一次打开 WorkBuddy，用了几分钟就觉得： “不就是又一个 AI 聊天框吗？” 其实不是工具没用，而是你一直在 Ask 模式里聊天，却没有把任务文件、工作目录和交付标准真正交给它。 WorkBuddy 的核心价值不是回答一个问题，而是读取资料、拆解步骤、调用工具，最后把文档、表格、PPT 或网页交付给你。 下面这份指南带你从安装开始，跑通第一个真实办公任务。 📌 1、WorkBuddy 到底适合谁？ 先说清楚：WorkBuddy 不是 Codex、Claude Code 的完全平替。 Codex 和 Claude Code 更偏专业编程、终端操作和复杂代码项目；WorkBuddy 更偏综合办公与任务交付，覆盖文档处理、数据分析、PPT、文件整理、研究、设计和简单开发等场景。 它更适合下面几类人： ① 日常办公任务繁杂的人 经常要写周报、整理会议纪要、分析 Excel、制作 PPT、汇总项目资料，希望减少在多个软件之间来回复制。 ② 不想折腾开发环境的新手 普通办公任务不需要先安装 Node.js、Python，也不用输入终端命令。使用内置模型时，无需自己配置 API Key，安装并登录后即可开始任务。 但要注…
