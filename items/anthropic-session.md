> 8 月 8 号，Claude 发布了一个新功能，现在两个 session 之间可以相互通信了。 如果你任务做到一半，想要重开一个窗口，一般这种情况下会重新介绍一下自己的身份，自己想要干啥，但现在不用了，你可以直接指派 Claude Code 来把这活干了就好。 我觉得这个功能很有用，希望 Codex、WorkBuddy、Trae、Qoder 等 Agent 赶紧推进下。 A 社还发布了一份官方文档，我看完了，给大家聊聊这篇文章都说了啥。 什么时候适合使用 官方列了四种比较典型的场景。 第一种移交发现结果：当一个 session 发现了某种重大变更，Claude 会把结果总结给相关 session，不用你自己再解释一遍。 第二种是协调平行 Worktree：几个 session 在不同 Worktree 里处理同一个 Repo，其中一个完成并提交了修改，可以直接通知其他 session 。 第三种是获取长任务状态：比如一个 session 在跑迁移或测试，完成之后可以向你正在使用的 session 递交报告。你也可以让当前 session 主动问它做完没有。 第四种是跨机器回复。 这里要注意，另一台机器或者 Claude C…
