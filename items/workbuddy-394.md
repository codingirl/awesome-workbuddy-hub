## 详情

> 我用 Workbuddy 生成文章插图也好，还是生成一些类似人像，或者产品也好。这个默认生图模型实在是太拉了。本来一开始呢，我走的是给 Workbuddy 做了个 Skill，直接调用中转站然后用 gpt image 2.5 生图，但是搭了这个 mcp 之后，我就豁然开朗了，直接把 mcp 作为连接器给 Workbuddy

## 使用/获取

- 一般做法：按原项目 README / `SKILL.md` 的说明，把 Skill 导入 WorkBuddy（或放入技能目录）。
- ⚠️ 安装第三方 Skill 前请审阅其来源、许可证、会访问的文件/账号/网络权限。
