> 朋友们大家好啊，我是金尘马。 有些朋友已经在用 Codex、Claude Code 这类 Agent，也想做 AI 知识库，却卡在了资料到底存哪里。 Obsidian 是一个非常受欢迎的本地知识管理软件。它基于本地文件，开放、可迁移，也很适合 Agent 操作。 但对部分刚开始接触知识库的用户来说，目录、Markdown 和多设备同步都需要学习成本。 如果平时已经在飞书里写文档，又希望手机、电脑随时访问，那么飞书文档 + 官方 Lark CLI，也可以成为一条云端知识库路线。 这篇文章只解决一件事：怎样把飞书变成 Agent 可以读取、整理和回写的云端知识库。 一、飞书文档知识库构成 云笔记主要解决保存、同步和搜索。AI 知识库还要能找到相关资料，理清它们的关系，并把整理结果写回文档。 一套能工作的 AI 知识库，至少有四个部分。 飞书知识库负责页面树和知识空间。 飞书文档负责保存具体内容。 Lark CLI 负责把文档能力交给 Agent。 Agent 加工作规则负责整理和维护。 可以把飞书理解成云端资料室，CLI 是 AI 操控云端资料室的工具，Agent 是进资料室干活的助手。 资料室搭好以后，还得给助手明确权限和规…
