# WorkBuddy 每日签到自动化 Skill

> 类型：技能（Skills） ｜ 分类：自动化 ｜ 标签：自动化

## 简介

让 WorkBuddy 安装该 Skill 即可自动完成每日签到与成长中心任务

## 详情

以下内容整理自原帖/文章（节选，未做编造；完整内容请见来源链接）：

> 不用手动签到了。 太爽了。 自动领 WorkBuddy 每日签到积分 + 成长中心全套自动跑完。 直接让WorkBuddy安装这个skill就行。

## 使用/获取

- 一般做法：按原项目 README / `SKILL.md` 的说明，把 Skill 导入 WorkBuddy（或放入技能目录）。
- ⚠️ 安装第三方 Skill 前请审阅其来源、许可证、会访问的文件/账号/网络权限。
