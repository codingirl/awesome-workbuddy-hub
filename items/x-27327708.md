> 大家好，我是萝卜哥~ 前段时间我开源了一个公众号排版 Skill，叫“萝卜排版”。把 Markdown 文章交给 Agent，它会按内容选样式，生成一个能直接复制到公众号的 HTML 页面。 目前在 WorkBuddy 上安装就能使用。 其实我个人觉得，想省事的时候这个 skill 已经很够用了。稿子丢过去，补一句“绿色，清爽一点，代码块保留”，一版就出来了。 只不过对于我这种公众号重度用户来说，单纯一个排版 skill 很多时候不够用。 比如说正文想再大一号，这段行距有点挤，引用框想换个颜色，代码块想换个底色。Skill 当然也能改，但每次都得重新描述，等它生成，再打开检查，这样来来回回其实效率更低，对于这种需要反复修改的场景，我更想自己上手，盯着效果慢慢来。 所以我又做了一个网站，现在它也开源了。 目前我只完成了第一版，首要目标就是把排版做扎实，喜欢自己改样式的朋友，直接在网页上动手就行。 基本功能介绍 打开网站，左边是 Markdown 编辑区，右边是文章预览。 和大多数排版网站一样，我也采用的左右同步渲染的策略，你在左边修改内容，右边会立刻显示出对应的效果。 现成的文章文件也能从本地导入，编辑区里已经有内容的话，它…
