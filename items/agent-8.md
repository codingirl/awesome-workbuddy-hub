> 有朋友问我，如果换了电脑，换了 Agent，如何迁移数据，使 Agent 还能记得我的上下文？ 我几个月前做的项目 build your harness 就是解决这个问题的，这次我做了全面升级。 harness 指的是在 AI 领域指的是模型之外、让模型能干活的整套结构。 可以分为两部分，一部分是 Claude Code、Codex、WorkBuddy、豆包工作已经定义好的工程环境。 还有一部分，是使用 Agent 的人自己决定的。 比如模型能读到哪些文件、能调哪些工具、记得什么。也就是我们和 Agent 对话的时候要选择的那个文件夹。 这部分得自己动手搭建，整理自己的上下文，换了不同的 Agent ，选中文件夹，就能让它知道你是谁，正在做什么。 我几个月前过的个人 harness 的搭建方法，做成了三个 Skill 放在 GitHub 上： 〔图片 3 上传未完成，请手动补充〕 star-your-harness：问你四个问题，按职业生成一套目录骨架，你自己去选择相关的内容，去按照骨架搭建上下文。。 better-your-harness：给现有的 harness 做体检，出一份 HTML 报告和修复口令。 view-y…
